# Maps

Export maps from `fantasy-map-generator/` (PNG/SVG or the Leaflet-ready
export) and drop the image files in `Attachments/Maps/`, then embed them
here, e.g.:

```
![[Attachments/Maps/world-map.png]]
```

For an interactive map, the `ttrpg` Quartz template ships with the
[Leaflet bases plugin](https://github.com/Requiae/quartz-leaflet-bases-plugin) —
see its docs for embedding a pannable/zoomable map instead of a static image.
